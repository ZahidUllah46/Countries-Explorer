#  Countries Explorer Web App

 Web Development Internship at Qwetrum Technologies

A fully responsive **Countries Explorer Web Application** developed from scratch using **HTML, CSS, and JavaScript**.

This project uses the **REST Countries API** to fetch live country data and display country flags, names, and population dynamically without using any frontend framework.

---

##  Features

✅ Fetches live data using JavaScript Fetch API  
✅ Displays country flags and population  
✅ Real-time search functionality  
✅ Dynamic country cards generation  
✅ Loading spinner while fetching data  
✅ Error handling with retry option  
✅ Responsive design for mobile, tablet, and desktop  
✅ Clean UI using CSS Grid and Flexbox  

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST Countries API
